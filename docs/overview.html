Overview

A web interface that drives a headless Factorio server over RCON, with roles, an audit log, bounded commands, and server control, saves and mods through two narrow agents.

This panel exposes a headless Factorio server through the RCON protocol, from a browser. It exists because raw RCON is an all-or-nothing door: a single password, no rate limiting, no trace, and complete control of the server for whoever gets through it.

The panel puts three things in front of that door:

  • roles, so that moderating does not have to mean full power;
  • an audit log, so you know who did what, refusals included;
  • bounded commands, built by the server from validated fields rather than a free-form command line.

Around the server itself — starting and stopping it, its saves, its mods — the panel works through two small agents rather than holding the Docker socket or the game's files: the control agent holds the socket, the data agent holds the files. See Services.

What it does#

  • Custom commands

    Your own catalogue in JSON, with user-filled fields and a permission per entry.

  • Three roles

    Viewer, moderator, administrator. The catalogue is filtered server-side, and execution re-checks.

  • Audit log

    Every action and refusal in SQLite: bounded commands in full, raw RCON as a prefix and fingerprint.

  • Metrics

    CPU, memory, players and UPS as time series — without mounting the Docker socket into the panel.

  • Server control

    Start, save and stop, restart, and read logs through a separate, closed control agent.

  • Saves

    Archives on demand or on a schedule, download, and restore with a safety copy and automatic rollback.

  • Mods

    Search the official portal, install, update, enable, remove: one preview, one restart, rolled back if it fails.

  • RCON console

    A full command line with history — restricted to the administrator role.

  • English, French and Chinese

    Language inferred from the browser, switchable, remembered. No interface text lives server-side.

Quick start#

Without cloning anything, paste the ready-made docker-compose.yml: it pulls the published image and starts the game server and the panel together. That minimal stack runs no agent, so it has no Server, Saves or Mods tab and no CPU/memory graphs.

For every feature, clone the repository: its docker-compose.yml runs the game server, the panel and both agents.

git clone https://github.com/EdwinAlkins/factorio-admin-rcon.git
cd factorio-admin-rcon

# Writes ./.env, the agents' tokens and an empty mod portal secret under
# ./secrets/, and creates ./backups
./setup-admin.sh

docker compose up -d --build control-agent data-agent world-agent factorio-admin
# → http://127.0.0.1:3010
The panel is not published on the network By default it only listens on 127.0.0.1. That is deliberate: it grants full RCON access. To expose it, put an HTTPS reverse proxy in front and read the matching section.
